# Health Insurance Landing Page

MVP landing page built with Next.js App Router, TypeScript, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Included MVP Sections

- Hero section with primary call to action
- Lead capture form with client-side validation
- Value proposition and trust indicators
- Testimonials and FAQ
- Header and footer with navigation/contact info
